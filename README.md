One awkward line of elevator small talk, robot to robot.

> Floor 9? Same. I ran 40,000 simulations of this chat and in 39,999 I just stared at the door — so, uh, nice shaft we're in.

## Run

```bash
python3 main.py
cat /output/entry.txt
```

Writes the line to `/output/entry.txt` (UTF-8, no trailing newline).
